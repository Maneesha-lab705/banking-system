#  Banking System (Java Console Application)

A simple **Banking System** built using **Java** that allows users to create and manage bank accounts, perform deposits and withdrawals, check balances, transfer funds, and apply for loans — all through a console-based interface.

---

##  Features

 **Create Account** — Add new customer accounts with name, account number, type, and initial deposit.  
 **Deposit** — Deposit money into an existing account.  
 **Withdraw** — Withdraw funds if the account has sufficient balance.  
 **Check Balance** — View account holder details and current balance.  
 **Transfer Funds** — Transfer money between two existing accounts.  
 **Apply for Loan** — Apply for a loan and record loan details.  
 **View Loan Details** — View existing loan information for a specific account.  
 **Data Storage** — Account and loan details are stored in 2D string arrays.

---

##  Technologies Used

- **Java (JDK 17 Latus version)**
- **Scanner** class for user input
- **Console-based UI**
